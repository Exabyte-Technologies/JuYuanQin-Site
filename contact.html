常见问题

你可能想知道

聚缘琴科技的核心工具收费吗？

我们的核心开源工具与资源可免费使用，具体项目请以各自说明为准。

开源项目可以用于商业用途吗？

请查看具体项目的许可证；符合许可证条款时，可以用于商业场景。

如何报告安全问题？

请将问题详情发送至 support@exabyte.org.cn，我们会认真处理并尽快回复。

在哪里查看项目文档？

项目文档与代码均可在 GitHub 查找；如果没有找到需要的内容，欢迎联系我们。

我不是开发者，也能参与吗？

当然可以。设计、写作、测试、反馈与分享，同样是重要的贡献。

如何了解最新进展？

关注 GitHub 项目或加入社区，即可查看发布、讨论与后续计划。
